# 启动提醒助手 · Windows 版

> 界面更新：2026-09-11。奶茶鼠尾草配色，日程、任务与独立专注集中在同一页。桌面入口与系统托盘提供随时唤出能力。

本版以 2026-09-10 确认的需求为准。提醒与专注是两个独立功能；不再需要每天进入 Quest。

## 开始使用

1. 双击桌面“启动提醒助手”快捷方式，或项目中的 `启动助手.vbs`。右上角最小化正常收进任务栏；点叉或 Alt+F4 隐藏到系统托盘，不退出后台。单击托盘图标可重新打开。
2. 首页左侧是今日安排，右侧是下一步任务，底部是独立专注入口。直接记录任务不需要 AI；圆形完成按钮或“搁置”会将任务移出待办。
3. Chrome 和 Edge 分别打开扩展管理页，开启开发者模式，选择“加载已解压的扩展”，选择本项目的 `extension` 文件夹。
4. 在桌面“设置 → 连接与配置”复制本机配对码，分别粘贴到两个浏览器扩展的设置页。它不是 AI 密钥。已配对的浏览器无需重新配对。两个浏览器在线后才能开始专注。
5. 专注前添加允许的视频或音乐链接，选择分钟数并确认结束时间。开始后无法通过助手提前结束或修改允许列表。

本版使用独立 Conda 环境 `study-reminder`：Python 3.12.14、PySide6 6.11.2，不改变 base 和其他科研环境。桌面、自启和 CLI 统一读取 `config/python-path.txt`，当前为 `D:\anaconda\envs\study-reminder\python.exe`。换电脑时运行 `conda env create -f environment.yml` 重建环境，更新该路径，再运行 `scripts/install.ps1` 注册桌面和登录启动入口。日常双击启动无需手动激活环境。

## 会议免打扰与快捷键

- 首页“会议免打扰”会立即收起主窗口、提醒卡片和已打开的辅助窗口，暂停全部自动提醒。无提示音、无托盘气泡。
- 会议模式只通过你手动恢复，关闭窗口或重新启动程序不会自动解除。
- 恢复方法：单击托盘图标后点“恢复提醒”，或右键托盘图标选择“恢复提醒”。也可用全局快捷键打开首页再恢复。
- 专注计时在会议模式下继续，到期照常解除网站限制；休息/专注结束及定时提醒不会在恢复后补弹。
- 默认 `Ctrl+Alt+Space` 显示/隐藏主窗口；`Ctrl+Alt+N` 打开快速记录窗口，输入后回车保存。
- 修改位置：**设置 → 快捷键**。点击对应输入框，按下新组合，然后点“保存快捷键”。支持 Ctrl/Alt/Shift 配合字母、数字、空格或 F1—F11；若被系统或其他程序占用，会提示更换，原快捷键尽量保留。按钮“填入默认组合”只填入，仍需保存。
- 全局快捷键和桌面快捷方式不是同一功能，两者都已提供。主动唤出窗口/快速记录在会议模式下仍可使用，不会自动恢复提醒。
- 需要真正退出时，在 **设置 → 后台与会议 → 退出后台程序**，或右键托盘选择退出，并再次确认；专注期间不能退出。

## 提醒

- 每日 09:00、14:30、19:00；普通周三增加 16:00。按实际教学周、放假和补课规则过滤上课时段。
- 登录电脑，或锁屏/睡眠至少 30 分钟后返回，08:30—22:30 内且不上课时提醒。
- “我开始了”只关闭提醒，不计时、不限制网站。直接点叉也只关闭本次。
- 休息可选 5 / 10 / 20 / 30 / 60 分钟或自定义；到期提醒一次，期间其他提醒照常。
- 普通定时提醒在关机、睡眠或上课时错过即跳过，不追补。
- 主动专注时暂停启动提醒，结束时通知一次。
- 同一分钟的固定安排与普通提醒合并，优先显示固定安排。多种事件同时到来时只展示一个提醒窗口。

固定安排：

| 安排 | 时间 | 适用范围 |
|---|---|---|
| 图论自学 | 周二 16:00—17:00 | 第 1—15 教学周；假日、补课日跳过，不自动改期 |
| 科研 | 周三 19:30—21:00 | 假日、寒假及旧课表到期后继续 |
| 科研 | 周六 09:30—11:30 | 同上 |
| 科研 | 周日 14:30—16:30 | 同上 |

物理实验仅 2026-10-12、10-19、11-09、11-23 的 19:30—21:55。周二图论叠课按课后自学处理，实际课程为模拟与数字电路。

校历教学周从星期日开始，第一周的星期一为 2026-08-31。2027-02-21 起停止旧课表的普通定时、登录与解锁提醒，以及图论安排；科研、任务、聊天与手动专注继续。配置新学期时更新 `config/schedule.json`，在窗口中重新读取。

## B 站专注

- 严格允许列表，仅放行指定 BV 号的视频页面，包含该视频各分 P。
- 音乐长视频可直接加入；课程合集在扩展设置页输入其中一个视频，点“提取所属课程合集”，核对各集 BV 号后点“加入桌面助手的允许列表”直接写入。
- 仅允许本次导入的合集成员。合集后续更新不会自动扩大本次允许范围。
- 开始时，其他已打开的 B 站页面会跳转到专注提示页；允许页面隐藏推荐、评论等干扰内容。
- 知乎及其他网站不受限制。空允许列表表示本次专注不使用 B 站。
- 计时按结束时间计算，睡眠和重启期间继续流逝。扩展保存结束时间与拦截规则，桌面窗口关闭不解除限制。
- 普通扩展不能阻止用户手动停用、卸载扩展或换用未安装扩展的浏览器/配置档。无痕窗口需用户在扩展管理页允许扩展在无痕模式中运行。
- 首次安装扩展后刷新已有 B 站页面。页面样式可能随 B 站改版变化，但视频网址允许列表独立于推荐区样式。
- Chrome、Edge 的“在线/正在同步/限制已同步”状态显示在桌面专注页。浏览器被系统暂停时同步可能延迟；看到两个“限制已同步”再开始使用。

## AI 配置（默认关闭）

编辑 `config/ai.json`：

```json
{
  "enabled": true,
  "base_url": "https://api.llm.ustc.edu.cn/v1",
  "model": "在这里填写当前可用模型名",
  "api_key": "在本机填写密钥",
  "api_key_env": "LLM_API_KEY",
  "timeout_seconds": 90,
  "parameters": {}
}
```

也可以不在文件填写密钥，改设环境变量 `LLM_API_KEY`；环境变量优先。模型没有写死，未来更换为其他模型时只修改 `model`。接口使用 `/chat/completions`，模型需支持该协议。可在 `parameters` 添加供应商支持的可选参数。配置每次请求重新读取。

程序会发送课表、未完成任务和最近 7 条复盘；CLI 连续聊天还会发送最近 24 条聊天消息。聊天与复盘保存在本机 SQLite 中。密钥不会发送到浏览器扩展或写入应用日志。无配置或 API 失败时，本地提醒、任务与专注仍可使用。

窗口中的 AI 拆解只生成草稿，可修改、指定日期，确认后才写入任务；不确认即不保存。普通聊天也不会擅自写任务。

## CLI

双击 `聊天CLI.cmd`，或运行 `D:\anaconda\envs\study-reminder\python.exe app.py cli`。

| 命令 | 用途 |
|---|---|
| `/tasks` | 查看所有待办 |
| `/add 打开实验记录` | 直接添加一个任务 |
| `/plan 明天准备推进仿真` | AI 拆解，输入 yes 后才保存，可指定计划日期 |
| `/done 3` | 完成编号 3 的任务 |
| `/shelve 3` | 搁置编号 3 的任务 |
| `/review 今天完成了……卡在……` | 保存复盘 |
| `/clear` | 确认后清空聊天历史 |
| `/quit` | 退出 CLI，不影响桌面助手 |

其他输入进入连续聊天。CLI 与窗口共享任务、复盘数据；CLI 不提供绕过专注的解除命令。

## 安装与维护

`powershell -ExecutionPolicy Bypass -File scripts/install.ps1 -CleanLegacy` 注册当前用户登录启动，删除旧 StudyReminder 计划任务及旧运行目录。此脚本需具备相应系统权限，重复执行不会重复创建启动项。Quest 任务不由此脚本控制。

文件位置：

- `config/schedule.json`：课程、校历、固定安排、默认动作与通用池。
- `config/ai.json`：AI 配置，默认关闭，模型和密钥留空。
- `data/reminder.sqlite3`：任务、复盘、聊天、休息和专注状态、本机配对码。
- `data/app.log`：运行错误与提醒事件，不记录 AI 密钥。
- `extension/`：两个浏览器共用的扩展源码。
- `tests/`：规则、持久化、API 模拟与扩展策略测试。

日常退出：在“设置 → 后台与会议”选择“退出后台程序”，专注期间不可退出。完全停止自动启动时删除当前用户启动目录中的 `StudyStartAssistant.lnk`。

验证命令：

```text
D:\anaconda\envs\study-reminder\python.exe -m unittest discover -s tests -v
node tests/extension.test.cjs
D:\anaconda\envs\study-reminder\python.exe scripts/smoke_gui.py
D:\anaconda\envs\study-reminder\python.exe scripts/status.py
```

`scripts/status.py` 只读查询实际扩展心跳、是否就绪和规则同步状态，不会启动专注或创建模拟连接。GUI 冒烟测试使用临时数据与独立端口，可与真实助手同时运行。

真实 API 可用性由后续配置后验证。浏览器安装配对、B 站课程播放与合集导入需真实浏览器验收；自动化策略测试不能代替真实网站验收。

## 提醒中的“换一步”

首次仍优先显示当前待办或固定安排。“换一步”会排除当前文案；待办和轻量动作都有可替换候选时，先按各 50% 选类别，再在该类随机选一项。某类没有替换项时改选另一类，因此单条待办不会连续出现，边界情况下不保证严格各半。

轻量动作共 12 条，保存在 config/schedule.json 的 generic_pool；light_action_contexts 使用从 0 开始的索引选择学习、代码、论文、科研类动作。按首次提醒的关键词选择场景，无法识别时参考当前固定安排；该筛选不调用 AI。默认提示也已缩小为阅读标题、单条笔记或只读题等动作。

“我开始了”仍只关闭提醒，不完成原待办、不计时、不自动开启专注。

## 暂缓提醒

提醒卡片左下角的“暂缓 5 分钟”会立即关闭当前提醒，5 分钟后再次提醒，可重复使用；不开始专注、不限制网站。原“休息一会”的自选时长功能保留。暂缓截止时间写入本地数据库，睡眠/重启期间时间继续流逝，锁屏期间到期则在解锁后提醒；会议免打扰或专注期间到期不弹出，也不补弹。暂缓当前提醒不屏蔽其他独立提醒。

## 专注时打开允许的视频

专注期间点击首页“已允许 X 个视频”，显示本次专注实际生效的允许列表；每项自动获取并缓存 B 站标题，同时显示 BV 号。点击“Edge 打开”使用 Microsoft Edge 打开该视频，分 P 可在视频页面中选择。页面不提供增删入口，专注结束或切换后旧页面不再打开链接。未专注时，该入口仍打开原有列表编辑界面。

标题通过 B 站公开接口在后台获取，不使用 AI、不需要登录；请求失败时仍可按 BV 号打开，重新打开列表时重试。不会修改已有允许列表或专注截止时间。

## B 站停留与自动专注规则

扩展 1.1.0 与桌面助手配合，合并 Chrome、Edge 的前台 B 站使用时间。只有浏览器窗口处于前台、选中的标签页是 B 站时才计时；后台音乐不计入，现有允许列表中的视频及分 P 不计入。短暂切走暂停累计，连续离开 B 站 5 分钟后清零。允许列表视频仍属于 B 站停留，但不增加计时。

每轮累计使用 20 分钟显示红色提示，并按现有规则抽取待办或轻量动作；保留换一步、休息、暂缓和进入专注入口。20 分钟提醒不清零累计时长。累计达到 40 分钟时，无需确认，自动开始 40 分钟专注，并关闭尚未处理的提醒；自动专注同样不能暂停、缩短或提前退出。沿用已保存的允许列表，空列表限制全部 B 站页面。自动启动不要求两个浏览器同时在线，在线扩展执行限制，另一扩展连接后同步；手动专注仍要求两个浏览器在线。

20 分钟提醒会等待已有提醒处理完成，40 分钟自动专注不等待。会议免打扰、专注和锁屏期间不计时，恢复后重新累计；专注结束后重新执行 20 分钟提醒、40 分钟自动专注的规则。扩展断连后最多沿用最后状态 12 秒，不补算未观察到的离线或睡眠时间。升级前已被旧版每 20 分钟清零的历史时长无法追溯，新版从当前保存的剩余时长继续累计。

升级启用：先保存未完成的编辑，然后重启桌面助手。在 Chrome 的 `chrome://extensions` 和 Edge 的 `edge://extensions` 中，找到本项目扩展并点击重新加载，确认版本为 1.1.0。两款浏览器均需操作，无须重新配对。仅重启桌面助手不会更新已加载的扩展。

扩展只向本机上报前台状态、是否为 B 站及视频 BV 号，不上报完整网址、标题或页面内容。该功能不使用 AI。自动化测试覆盖计时规则和页面分类，真实浏览器的前台切换与 20 分钟提醒仍需实际使用验收。
